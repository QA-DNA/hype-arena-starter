Essential Tactical Insights for the Arena

1. Temporal Evolution & Changing Facts

The universe spans from Oct 2025 to Oct 2026. Metric values (prices, staff, versions) change over time. The contest deadline references values on 29 Oct 2026.

2. Deterministic Claim Generation

We must generate exactly 1,000 new, true claims in the format of fact, compare, change, at_event, or relation. All entity and attribute names must strictly conform to lexicon.json.

3. The 14.6% Falsehood Rate

False sentences represent pages that lie, outdated claims, or incorrect numbers. Catching false values requires tracking the latest ground truth per (subject, attribute) pair.

4. The "Unsure" Catch-all

Sentences that state facts whose values cannot be confirmed or disproven from the dataset must be labelled unsure with no confidence score.
