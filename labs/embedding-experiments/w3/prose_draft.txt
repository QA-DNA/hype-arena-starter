# w3: static vs transformer vs LLM embedders

Harness defaults throughout (page folds, C=10 probe, 2 threads, shared Mac arm64, so speeds are indicative). SAFE = static or non-neural (no transformer at runtime); GREY = multilingual encoders; RISKY = Qwen3-Embedding-0.6B (decoder LLM, fp32, batch 16, instruction on rows only) and nomic-v2-moe (encoder MoE). Rows get the query prefix (e5 "query: ", nomic "search_query: ", Qwen3 instruction), descriptions the document side (nomic "search_document: ", e5 "query: ", Qwen3 none). LSA-300 and RP-512 are label-free TF-IDF references fitted on all texts. Hybrid = z(probe log-prob) + z(zero-shot cosine) over the gold subject's attributes; a candidate the probe never saw gets z=0 (a "veto" variant is also logged). Tables are sorted by the first metric, so rows 1-3 are the top-3. Extras: `;centered` variants (mean vector removed), Qwen3 without instruction, probe-weight sweep. Fold noise is about 0.01, so smaller gaps are ties.

Top-3 (raw): probe static-sim-multi, LSA-300, para-MiniLM; kNN LSA-300, static-sim-multi, Qwen3; zero-shot potion-32M, potion-8M, Qwen3 no-instr; hybrid nomic, static-sim-multi, potion-8M; leave-attribute-out hybrid LSA-300, static-sim-multi, nomic; key retrieval LSA-300, Qwen3, nomic; false AUC e5-small, static-sim-multi, potion-32M; 3-class RP-512, static-sim-multi, LSA-300; speed glove, potion-8M, potion-retr-32M.

**Static vs transformers.** Close on every task (gap at most 0.015). Probe: best static 0.868 vs best encoder 0.859, nomic 0.855, Qwen3 0.839. Zero-shot: static 0.841 vs 0.831. Hybrid: static-sim-multi 0.913 and potion-8M 0.902 (31 MB, 56k sents/s) vs 0.873 for TF-IDF; the 76 rows with no training example go from 0.000 to 0.50-0.66. The gain is zero-shot fusion: no embedding probe beats TF-IDF on attributes with 1-4 examples (0.883).

**LLM ceiling.** Not meaningfully higher. Qwen3 is below the best static model on probe (0.839 vs 0.868), zero-shot (0.802 vs 0.841), hybrid (0.896 vs 0.913), key recall (0.662 vs 0.702) and AUC (0.577 vs 0.608). Its instruction does not help (no-instr: zero-shot 0.831, probe 0.836, hybrid 0.894) and costs 20% speed (about 4,500 s per 20k texts on x86). Best RISKY is nomic: hybrid 0.919 raw, 0.933 centered, against 0.913 and 0.918 for static, at 46 sents/s against 29k-56k and 1.9 GB against 31-436 MB.

**Surprises.**
1. Anisotropy: the C=10 probe stops after 32-60 lbfgs iterations on L2-normalised vectors and punishes encoders with high mutual cosines. e5-small 0.722 raw, 0.864 centered (ge5 0.988); Qwen3 0.839 to 0.873. Centered, all top probes sit at 0.866-0.873, so raw encoder rankings partly measure geometry.
2. The 1:1 hybrid hurts unseen attributes: leave-attribute-out hybrid 0.443-0.622 is below zero-shot alone 0.686-0.841 for all 13 models. Sweep: probe weight 0 is best there (potion-8M 0.835, 0.781, 0.718, 0.530, 0.157 for weights 0, 0.25, 0.5, 1, 2), while weight 1 is best or within 0.02 on page folds. Next test: mute the probe on low-confidence rows.
3. Lexical wins retrieval and truth: only LSA-300 (0.702) beats TF-IDF char recall@10 0.666; no model reaches AUC 0.633 (best 0.614); every 3-class arena_best (0.122-0.288) is far under 0.687.
4. LSA-300 (8M params, 7,440 sents/s) is a strong non-neural baseline: best kNN, second-best SAFE probe.

**Failures.** embeddinggemma-300m: gated (401, no token); logged with status=failed and skipped. nomic: first run failed (transformers 5.21 removed `get_extended_attention_mask`, which its remote code still calls); the second run used a 6-line shim, padding invariance checked (cosine 1.000000), remote code grepped first (no network, exec or env access). My bugs, fixed and re-run: `max_seq_length=inf` crash on static models, GloVe disk double-count (964 to 485 MB). Verified: the probe-recording subclass reproduces the unpatched harness exactly (potion-8M 0.836/0.948/0.819); hybrid code checked against zero-shot and probe at weight 0.
