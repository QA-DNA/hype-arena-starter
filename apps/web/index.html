BUILT TO RUN. BUILT TO EXPLAIN.

A complete path from input to output.

The browser and competition CLI call the same Rust core. All inference runs on CPU, offline.

INPUT

What enters?

Each runtime row has id, text, date and label. A missing label is a prediction request. The lexicon defines valid subjects, aliases and attributes.

REASONING

What does the engine do?

Mihai's normalization resolves aliases. Templates extract typed assertions. The 48-tree forest combines lexical, value and evidence features; source rows and dates remain inspectable.

GENERATION

What makes a new claim?

Explicitly true source observations license candidates. Model-predicted truth alone does not. Contract templates construct the text and form; MMR balances support with diversity.

VERIFICATION

How do we test it?

The accuracy test removes held-out text, labels and forms before training. Schema checks validate output structure. Neither a model score nor a schema check proves hidden-universe truth.
